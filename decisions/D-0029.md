**Decided:** A push that is not a fast-forward is never forced by the agent or by a script. The push script prints a VERDICT HUMAN line with the exact force command and exits 2; the agent first offers the forward fix (reset to origin's tip, re-apply the file state as a new commit, push fast-forward) and hands the force command to the human only when the forward fix will not do.

**Because:** The client layer already denies git push --force (S-11), so an agent rebase of a pushed branch could not be completed; S-17 showed the forward fix reaches the same MR diff without any force.

**Applies when:** Backs the boolean force_push_is_human. Any push of a branch that already exists on the remote.

**Does not apply when:** A branch that has never been pushed, and a fast-forward push.
