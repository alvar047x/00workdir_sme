**Decided:** Do not request code review until the merge request pipeline has passed.

**Because:** Review of a change that cannot build is wasted, and a red pipeline usually changes the diff, invalidating the review.

**Applies when:** Any merge request with a pipeline configured (.gitlab-ci.yml present).

**Does not apply when:** Repos with no pipeline (azure_titan, silvercloud-gc-docker-images per manifests).

**Replaces:** none
