**Decided:** Bring the base branch up to date (fetch and pull) before creating a working branch from it.

**Because:** Branching from a stale base produces a diff against history that no longer exists, which surfaces later as a merge conflict or a silently reverted change. User stated 2026-09-11.

**Applies when:** Any creation of a working branch in any repo under clonedRepos.

**Does not apply when:** 00workdir, which is worked on directly. Branches created by tooling that already pulls (at repo pull).

**Replaces:** none
