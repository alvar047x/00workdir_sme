**Decided:** at.py verbs are run as `atpy <verb> ...` from any directory. `atpy` is a wrapper on PATH at /opt/homebrew/bin, linked to automation_tools/bin/atpy in 00workdir, and keeps the caller's working directory. The long form `python3 automation_tools/at.py <verb>` from 00workdir is equivalent. Bare `at` is the Unix scheduler and is never used.

**Because:** A short name saves tokens and typos on every call, and a name that does not collide with `at` removes the failure seen in the first Kiro session. Keeping the caller's directory matters because `sme resolve` selects the repo manifest from cwd.

**Applies when:** Any use of an at.py verb.

**Does not apply when:** Hook wiring inside hook-runner.sh, which resolves the python path itself. A machine without the symlink, where the long form is used until `ln -s` is run.

**Replaces:** D-0018
