**Decided:** Before the first aws, kubectl, skopeo, or terraform command in a session that touches an AWS account, run `aws sts get-caller-identity --profile <target>` and state the account and profile in the response.

**Because:** Sixteen profiles exist across build, qa, stage, eight prod regions, ECR, titan, and hospital. A command against the wrong account fails silently or mutates the wrong environment. Stating the identity makes the target reviewable before anything runs.

**Applies when:** The first AWS-touching command per profile per session, and again after any re-auth.

**Does not apply when:** Commands that do not reach AWS (terraform fmt, validate with -backend=false, local git).

**Replaces:** none
