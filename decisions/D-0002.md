**Decided:** Branch names carry the ticket key: DVPS-<ID>-<desc>; feature/ and fix/ prefixes for those types. Repo-specific patterns in the repo manifest win.

**Because:** The ticket key in the branch name links a branch to its Jira record without a lookup table and is what the MR tooling reads. topology.yaml records per-repo patterns (silvercloud-web-infra uses feature/DVPS-XXXX-desc; terraform-aws-pexip-common uses feature/desc or fix/desc with no key).

**Applies when:** Any creation of a working branch for a Jira ticket.

**Does not apply when:** Repos whose manifest states a different pattern (terraform-aws-pexip-common). Branches that are not ticket work (release, hotfix by maintainers).

**Replaces:** none
