**Decided:** Pipeline work uses `at gitlab pipelines`, `pipeline <id>`, `job <id>`, and `monitor <id>`, always with `--project <slug>` because the default project is silvercloud-web-infra. A failed job is read with `at gitlab job <id>` and the stage plus first error line are cited before any retry. The agent never triggers an apply; that is a human click in GitLab.

**Because:** Improvised pipeline monitoring is where Kiro lost the thread most often. Four verbs and one flag cover list, detail, trace, and watch.

**Applies when:** Any pipeline list, status check, job trace, or MR pipeline wait.

**Does not apply when:** MR diff and comment review, which use `at gitlab diff` and `at gitlab comments`.

**Replaces:** none
