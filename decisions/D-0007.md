**Decided:** All agent output and commit messages are plain ASCII with no em-dashes. Conversational summaries stay within five sentences.

**Because:** Stated user preference for prose and commit messages. Non-ASCII characters break terminals and commit tooling the user relies on.

**Applies when:** Every response and every commit message.

**Does not apply when:** File contents that require other characters (data files, existing non-ASCII content being edited).

**Replaces:** none
