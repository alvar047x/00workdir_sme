**Decided:** Consumers reference terraform-aws-pexip-common by a released tag, never by a branch name.

**Because:** A branch-pinned module changes underneath a reviewed plan; the apply then diverges from what was approved. The repo publishes tags on every release for exactly this purpose.

**Applies when:** Any module source line in a consumer repo (infra-central and others) that points at terraform-aws-pexip-common.

**Does not apply when:** A short-lived test branch in a sandbox account, stated in the ticket, and never merged with the branch ref in place.

**Replaces:** none
