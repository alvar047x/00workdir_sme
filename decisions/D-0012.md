**Decided:** Do not run terraform validate or plan inside terraform-aws-pexip-common on its own. Run terraform fmt locally; validate and plan through the consumer (infra-central) against the module ref.

**Because:** The module requires provider aliases that do not exist in isolation, so an isolated validate fails for reasons unrelated to the change and trains the agent to ignore failures.

**Applies when:** Any change to .tf files in terraform-aws-pexip-common.

**Does not apply when:** The pipeline itself is changed to add a self-contained validate job, at which point this decision is superseded.

**Replaces:** none
