**Decided:** Every at.py verb is run as `python3 automation_tools/at.py <verb> ...` from 00workdir. Bare `at` is the Unix scheduler and is never used.

**Because:** No alias exists on this machine or in Kiro's shell, and a wrapper named `at` would shadow a system command.

**Applies when:** Any use of an at.py verb (jira, gitlab, gate, repo, sme, and the rest).

**Does not apply when:** Hook wiring inside hook-runner.sh, which already resolves the python path itself.

**Replaces:** none
