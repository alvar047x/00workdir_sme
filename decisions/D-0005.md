**Decided:** Every merge request carries the Jira ticket key in both the title and the description.

**Because:** The title appears in review queues and commit history after merge; the description is what Atlassian integrations parse to associate the MR with the ticket.

**Applies when:** Any merge request for ticket work.

**Does not apply when:** MRs opened by pipelines or bots.

**Replaces:** none
