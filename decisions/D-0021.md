**Decided:** Pull with `at repo pull <name>` before branching and push with `at repo push`. The Reaper Gate (`at gate check`) runs from the hooks on every shell call and blocks apply, destroy, and push without a cleared manifest; the agent never works around it and never calls `at hooks` targets by hand. `at gate doctor` is the check that hook files load.

**Because:** These are the only sanctioned write paths into a repo and the gate is the one control that stops a bad apply. Naming them once here replaces three archived steering files.

**Applies when:** Any git pull, push, terraform apply or destroy, or hook troubleshooting.

**Does not apply when:** 00workdir itself, which is committed and pushed directly.

**Replaces:** none
