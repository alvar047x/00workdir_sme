**Decided:** A prompt in everyday language is classified by the agent, not typed as an intent. When a script will run, the agent writes one record: the words verbatim, the script chosen, the ticket and repo resolved, the D ids applied, the booleans those settle, the open questions with defaults. One executor validates the record and runs the script; the reply quotes the verdict line. A lookup is the brief alone with no record. A post to Jira or GitLab (comment, create, transition, MR text) carries the user's permitting words in the record's approval key, or it does not run. A step the user says is done is marked done with their words through the executor.

**Because:** The verb inventory produced deviations every session because verbs were single API calls the agent composed by hand (S-43: five worked, four half, three missing). The judgment belongs to the agent, the consistency to decisions and manifests, the hands to scripts that choose their options from the record (S-45).

**Applies when:** Backs the booleans post_needs_approval and step_satisfied_by. Every prompt on a ticket in the session set that leads to a script run, and every post the agent proposes.

**Does not apply when:** A read-only lookup answered by the brief, and a prompt that fits no script, which gets a plain-words reply naming the nearest scripts and no record.
