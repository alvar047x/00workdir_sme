**Decided:** Commits use a semantic type (feat, fix, chore, refactor, docs) with the ticket key as scope: feat(DVPS-1234): short description.

**Because:** The type carries intent a diff does not; the scope carries the ticket key into git history. terraform-aws-pexip-common additionally releases from conventional commits, so the type controls the version bump.

**Applies when:** Any commit in a repo under clonedRepos for ticket work.

**Does not apply when:** 00workdir commits, which use type(sme) or type(kiro) scopes. Merge commits created by GitLab.

**Replaces:** none
