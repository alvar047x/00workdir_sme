**Decided:** Closing a ticket is two commands: one closing comment with `atpy jira comment`, then `atpy jira transition KEY --status Closed` (or the project's terminal status). The user's instruction to close is the approval. If the pre-close gate blocks, report its one-line reason and stop; never build plan, verification, or pattern files to satisfy it, and pass `--force` only when the user says so.

**Because:** The last close attempt spent twelve tool calls building legacy artifacts for a gate whose evidence is now the session log. Two commands is the whole job.

**Applies when:** Any request to close, resolve, or mark done a Jira ticket.

**Does not apply when:** The ticket has no session log at all; then one `atpy sme log add` entry stating what was done comes first, which is a third command, not an investigation.
